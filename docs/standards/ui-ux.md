# هله‌دان — هویت بصری و رابط فارسی

نام فارسی محصول همیشه «هله‌دان» و نام لاتین آن `heledone` است. واژه کاری رابط «تسک» است؛ در معرفی عمومی می‌توان «کارهای تیم» نوشت.

## رنگ‌ها

رنگ برند، سطح و وضعیت مستقل‌اند. توکن‌ها در `apps/web/src/index.css` و معنای وضعیت در `apps/web/src/core/config/designTokens.ts` تعریف می‌شوند. رنگ پروژه فقط تزئین است و نباید رنگ وضعیت، متن یا تأیید و خطا را تعیین کند.

| نقش | مقدار روشن | کاربرد |
| --- | --- | --- |
| بوم | #FFF8EE | زمینه اصلی |
| سطح | #FFFFFF | کارت، جدول و فرم |
| متن | #173C46 | متن اصلی و تیتر |
| متن ثانویه | #52666C | توضیح و فراداده |
| اقدام | #087F83 | عنصر فعال و دکمه اصلی |
| اشاره اقدام | #006D73 | دکمه در حالت اشاره |
| مرجانی | #DF765B | نقش برند و جزئیات تزئینی |
| زرد | #F2BA49 | تأکید تصویری |
| خط سطح | #DCE6E2 | مرزبندی محتوا |
| کنترل | #778C8F | مرز قابل‌تشخیص ورودی |

حالت تیره پالت مجزایی دارد؛ متن دکمه‌های روشن در آن نفتی است. رنگ‌های وضعیت روشن: خاکستری #52666C، فیروزه‌ای #087F83، کهربایی #8A5700، سبز #24734D و قرمز #B3343B. همه وضعیت‌ها برچسب متنی دارند. گزارش و کانبان از یک نگاشت مشترک استفاده می‌کنند.

«مسدود» ویژگی مانع تسک است و وضعیت گردش کار را جایگزین نمی‌کند. برچسب قرمز همراه وضعیت اصلی دیده می‌شود؛ توضیح یا دیدگاه محل ثبت علت و قدم بعدی است. پس از رفع مانع، همان کنترل آن را پاک می‌کند. مدل داده فعلی برای علت مانع فیلد مستقل ندارد.

متن برچسب‌های روی سطح رنگی از جوهر تیره‌تر اختصاصی استفاده می‌کند (فیروزه‌ای #005B60، سبز #1C603F، کهربایی #744800، قرمز #982B31). ترکیب‌های دکمه و برچسب روی رنگ با شفافیت ۱۰ تا ۲۰ درصد در هر دو تم سنجیده شده‌اند.

فوکوس از خط تزئینی مستقل است و با حاشیه واضح ۲ پیکسلی نمایش داده می‌شود. برای غیرفعال‌بودن کنترل، سطح و متن مجزا استفاده شود؛ کاهش شفافیت راه پیش‌فرض نیست. کنتراست هر ترکیب جدید، از جمله تیرگی، اشاره و رنگ سفارشی، دوباره سنجیده شود.

## نقش‌ها و ریتم

نشان اختصاصی سه ضرب نامتقارن فیروزه‌ای، مرجانی و زرد دارد. `Brand`، `BrandBeats` و `BrandWave` در کامپوننت مشترک برند قرار دارند. نقش نقطه‌وخط، شبکه هندسی و قاب نرم به‌صورت SVG/CSS محلی اجرا شده‌اند.

شبکه هندسی برداشت انتزاعی از شناشیر است؛ تصویر مستند معماری یا پوشش مردم نیست. مرجع توسعه نقش: [شناشیر و تصاویر معماری بوشهر](https://www.memar.io/en/magazine/articles/shanashir). هر تصویرسازی روایی آینده باید از عکس واقعی و با بررسی پوشش و معماری ساخته شود.

ورود و شروع همکاری می‌توانند قاب و نقش بزرگ داشته باشند. خانه فقط خوشامد کوتاه دارد و اطلاعات کاری اولویت دارد. نقش در کانبان، گزارش و حقوق به سربرگ یا حالت خالی محدود شود. فاصله‌ها بر شبکه ۴ پیکسل و حرکت‌ها بر زمان‌بندی مشترک ۱۲۰، ۱۸۰ و ۲۸۰ میلی‌ثانیه استوارند. تنظیم کاهش حرکت سیستم رعایت می‌شود.

پخش خودکار موسیقی وجود ندارد. هر صدای آینده فقط با انتخاب مستقیم کاربر فعال شود. تکمیل تسک بازخورد مختصر می‌گیرد؛ جشن بزرگ برای هر تسک استفاده نشود.

## فارسی و تایپوگرافی

وزیرمتن متغیر نسخه 33.003 از [مخزن رسمی](https://github.com/rastikerdar/vazirmatn/tree/v33.003) با مجوز OFL در `public/fonts` میزبانی می‌شود. رابط برای دریافت فونت به سرویس خارجی وابسته نیست؛ مجوز همراه فایل نگهداری شود.

| عنصر | اندازه |
| --- | --- |
| متن عمومی | ۱۶ پیکسل |
| جدول و کارت متراکم | ۱۴٫۵ پیکسل |
| توضیح و فراداده | حداقل ۱۳ پیکسل |
| تیتر کارت | ۱۸ تا ۲۰ پیکسل |
| عنوان صفحه | ۲۴ تا ۳۲ پیکسل |
| تیتر معرفی | ۴۴ تا ۶۴ پیکسل |

ارتفاع خط متن فارسی ۱٫۷ تا ۱٫۷۵ است؛ تیترها ۱٫۶ دارند. فاصله حروف فارسی اضافه نشود. صفحه اصلی `lang="fa" dir="rtl"` دارد. ایمیل، رمز، شناسه و متن لاتین باید جهت مستقل داشته باشند؛ متن ورودی کاربر از `dir="auto"` استفاده کند. جدول و ارقام کارکرد و حقوق باید tabular باشند. تیتر تسک و اطلاعات مانع کامل و قابل شکستن خط بمانند؛ توضیح ضروری صرفاً در tooltip نباشد.

وابستگی یعنی «تسکی که باید پیش از تسک دیگر انجام شود»، ظرفیت یعنی «زمان یا توان در دسترس تیم» و همسویی هدف یعنی «ارتباط کار تیم با هدف پروژه». در اولین استفاده توضیح کوتاه ارائه شود.

## بازبینی محلی

`npm run web:build` و `npm run web:lint` بررسی‌های اصلی‌اند. برای پیش‌نمایش مستقل از بک‌اند:

```sh
VITE_USE_MOCK=true npm --prefix apps/web run dev
```

با نام کاربری `admin` و یک رمز غیرخالی آزمایشی وارد شوید. داده‌ها ساختگی و در حافظه‌اند. مسیرهای `/dashboard`، `/tasks?project=1&board=1` و `/finance/my-reports` برای بازبینی خانه، وضعیت‌ها، متن بلند و ارقام فراهم‌اند. داده‌های نمونه این سه صفحه ساختگی‌اند. مسیرهای بدون هندلر آزمایشی از تنظیم بک‌اند استفاده می‌کنند؛ آزمون کامل محصول با بک‌اند نیز انجام شود.

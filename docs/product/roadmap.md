# نقشهٔ راه محصول مدار

این فایل خلاصهٔ اجرایی PRD موجود در `مدار.docx` است. سند اصلی، چشم‌انداز ۱۸ ماژولهٔ محصول است؛ همهٔ ماژول‌ها قرار نیست در MVP پیاده‌سازی شوند.

## چشم‌انداز

مدار یک سیستم‌عامل داخلی برای تیم است که مدیریت پروژه و تسک، ارتباطات async، ثبت زمان، انگیزش، سلامت کاری و رشد سازمانی را حول هستهٔ سازمان و پروژه‌ها یکپارچه می‌کند.

## فازهای تحویل

### فاز ۱ — Core MVP

هویت و سازمان‌دهی، پروژه‌ها، تسک و Kanban، تایم‌ترکینگ و حضور و غیاب پایه، داشبوردهای پایه و اعلان‌های ضروری.

### فاز ۲ — Operations & Motivation

گیمیفیکیشن، حقوق و پاداش، مرکز درخواست‌ها، ارزیابی عملکرد، فرهنگ سازمانی، جستجوی سراسری و یکپارچگی Git.

### فاز ۳ — Enterprise & Analytics

OKR، ویکی و مدیریت دانش، Well-being و تمرکز، ظرفیت‌سنجی منابع، سلامت پروژه، تحلیل پیشرفته و اتوماسیون‌های پیچیده.

## وضعیت فعلی در کد

هویت، سازمان، پروژه، اعضا، milestone، Kanban، task، subtask، checklist، comment، activity، standup، timer، attendance، notification/automation و پایهٔ گزارش‌ها در repository وجود دارند.

موارد ناقص یا نیازمند توسعهٔ بعدی شامل resource allocation، timeline/Gantt، dependency واقعی، labels، داشبوردهای غنی‌تر، workflow درخواست‌ها، گیمیفیکیشن، payroll، performance، OKR، knowledge، wellbeing analytics، global search، project health و Git integration هستند.

## قانون توسعه

هر فیچر باید به‌صورت یک vertical slice کامل از مدل و migration تا API، permission، کلاینت فرانت، UI و تست پیاده شود. منطق کسب‌وکار در service layer باقی می‌ماند؛ دسترسی سازمانی/پروژه‌ای در backend enforce می‌شود و ارتباط‌های آینده از طریق event/activity و رکوردهای audit قابل توسعه نگه داشته می‌شوند.
